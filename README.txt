Stielke App (PWA)
=================
URL: https://www.allround-service-stielke.com/app/

Installieren (Handy):
1. Seite im Chrome/Safari öffnen
2. „Zum Home-Bildschirm“ / „App installieren“
3. Startet wie eine native App (ohne Browser-Leiste)

Inhalt:
- Start / Leistungen
- Tarife
- Anfrage (Formspree)
- Stellenbörse
- Kontakt (Telefon, WhatsApp, Maps)

Gleiche Firmendaten wie die Website.
